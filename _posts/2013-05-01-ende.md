「**〇円でいいよ**」とは、値引き時の表現。主に売り手による「千円でいいよ、まけておくよ」。これは1920年代から文献に存在する。<br>
1980年代になると自由恋愛が進み、合コンが増えた。「**女のコは千円でいいよ**」と、安い金額をもらうのに使いはじめた。**これを女は喜んでいた**ということが文献に確認できるし、下記のように2016年でもぜんぜんある。

<blockquote>
職場の飲み会で女子が男性にされたい気遣い（略）「全額でなくても女性は1,000円でいいよ、とか」
</blockquote>
{{ site.p.cite }}ファナティック
「[キュンとしちゃう！職場の飲み会で女子が男性にされたい気遣い](https://woman.mynavi.jp/article/160905-176/)」（マイナビウーマン、2016年9月5日）{{ site.p.endcite }}

しかし2010年代から、これにキレる女が現れる。長い歴史がある普通の表現なのに。安くなっていないのに「円でいいよ」と言った男に怒っている例は、正しいので取り上げない。<br>
これまでとは違う、変なところで怒っている。
- 全額出して、と怒ってる。
- 「円でいいよ」という言葉が上から目線だと勘違いして怒ってる。
- 「円でいいよ」と言われるくらいなら、割り勘にしろと怒ってる。

**2020年以降、婚活女の中に増殖していく**。こんな気難しい女のほうに同調してくと、除外する男が増えて自爆だと思うが。統計は、X上に婚活クラスターの投票がある。<br>
質問「5000円の食事の請求はどれがいい？1000円ちょうだいは無理、という婚活女が時々いるが」
- 35.9% 1000円でいいよ（1000円ちょうだい）
- 25.0% 2000円
- 39.1% 2500円（割り勘）<br>
（2023年、5820人の自称女。男性分を除外し再計算済み）<br>
{{ site.p.cite }}「[結婚物語 @NakoudoT](https://x.com/NakoudoT/status/1689542961825263616)」（X、2023年8月10日）{{ site.p.endcite }}

再計算して5820人の女の投票であり、多いので不正による偏りは出にくいかと。以降でも言及するが、割り勘希望の女は多い傾向があるので、そっち側に数値が偏ると思う。この婚活クラスターの投票でも、**3人に1人の女は「1000円でいいよ」でもいい**ということで、あまりに毛嫌いしているのは少数派なんじゃないか、と思うけどな。嫌がる女の競争相手は、大量にいる「1000円でいいよ」でもいい女だよ。気難しくない女、男にとっても楽です。

### 奢ってよ、と怒ってる。

これまでは安くなってラッキーだったのに。この時代逆行は女にも不利でしょう。

<blockquote>
恩着せがましい（略）1,000円でいいよって言われたとき。1,000円くらい払ってよ！
</blockquote>
{{ site.p.cite }}加藤楓「[この男性ケチだなあと思ったことは？](https://woman.mynavi.jp/article/130501-010/2/)」（マイナビウーマン、2013年5月1日）{{ site.p.endcite }}

2010年代でも割り勘を求める女は多く、奢ってくれというのはマイナーな感覚です。

例えば、18歳以上のバイトしてる大学・短大生の統計。女はどうしたい？（2014年）
- 63% 割り勘
- 25% 男多め (男が67%負担)
- 5% 男多め (男が80%負担)
- 6% 男 (男が100%負担)

もう男が全額の時代ではないとして、「円でいいよ」という提案の仕方に言及している。ジェンダー平等が進んでいくのみで、少なくなり続けてる男を求めても自爆です。

{{ site.p.cite }}「[同い年の気になる人と初デート。6000円の食事代をあなたならどう割る？](https://townwork.net/magazine/job_wpaper/st_trend/7582/)」（タウンワークマガジン、2014年7月31日）{{ site.p.endcite }}

### 「円でいいよ」という言葉に怒ってる。

これまで30年間は、飲み会などで使われてきた普通の言葉の慣習だったのに、言葉に対して怒り出した。これまでずっとそういう言葉の慣習なんだから、今さら少数派の感性に同調して怒ってても、そういう男に会い続けるでしょう。無駄な抵抗ですよ。

<blockquote>
飲み会とかでよく耳にする、「2000円でいいよ」っていうあの上から目線。（略）「ゴメン、2000円だけもらっていい？」って言われれば、全然印象が違うのに！
</blockquote>
{{ site.p.cite }}「[女子が嫌いな「金持ち男」の特徴](https://nikkan-spa.jp/652988)」（日刊SPA!、2014年7月20日）{{ site.p.endcite }}

<blockquote>
「○○○○円で“いいよ”」という上から目線のフレーズを使う（略）上から目線で言われるくらいならきっちり払ったほうがまし。
</blockquote>
{{ site.p.cite }}酒豪ガール「[ケチは不快！？](https://woman.mynavi.jp/article/140905-25/2/)」（マイナビウーマン、2014年9月5日）{{ site.p.endcite }}

### 2019年

以上の通り、2015年まではのサイトは非常に少ない（2026年調べ）。ネット上ではマイナビウーマン、SPA、pairsが、これまでと異なった論調で怒りはじめたということだ。

上から目線とはいうけど、まったく違いますよ。売り手が「1000円」でいいよと100年前から言ってきたんだから、当然、上から目線ではなく、「1000円にまけられるよ」「1000円だけで大丈夫だよ」といった、対等なニュアンスでしょう。だから男が女に言っても「1000円で大丈夫だよ」といったニュアンスでしょう。これを「1000円にしてやるから買えよ」、「1000円だけでゆるしてやるよ」みたいに捉えているわけで、読書経験の不足や、飲み会などの経験不足から来ているんじゃないかと思うけど。

<blockquote>
『2,000円でいいよ』と上からのように言われるとイラッとすることがあります。500円多く払ったからといって結構偉そうな顔をされて（略）割り勘のほうがまだ良い
</blockquote>
{{ site.p.cite }}上岡史奈「[「何かイラッとする…」上から目線な男性の発言3つ!?？](https://classy-online.jp/couple/24675/)」（CLASSY、2019年2月6日）{{ site.p.endcite }}

</blockquote>
{{ site.p.cite }}ミノワリク「[飲み会で女子に「1000円だけ払って」はダサい？炎上中の本人を直撃](https://bizspa.jp/post-222508/)」（biz SPA!、2019年10月27日）{{ site.p.endcite }}

### 2020年代、婚活女の中に増殖し始める

2020年前は、上記のように、まだまだ数えるくらいしか記事はない。あとやっぱ記事を何個作ってんだってのは、マイナビウーマンですね。

2020年以降は、婚活クラスターの中に増殖していっているようだ。それでも記事は多くない。冒頭で言及したように、婚活クラスターの投票でも、3人に1人の女は「1000円でいいよ」でもいい。わりと気にしない女が多い。需要もある。なぜなら、これまで文学や飲み会とかで普通のことだったから。だから今後も消えることもないでしょう。この歴史に対抗して、今さら、こんなことを気にしてたら、少数派の気難しい女になってしまっている。そこに気を付けた方がいいと思います。
